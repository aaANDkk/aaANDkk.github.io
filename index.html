A COLLECTION, READY TO GO

把整套图标，放进客户端。

适用于同时支持 JSON 图标集与 SVG 图片的客户端，例如 FlClash、Bettbox。

  1. 复制订阅链接使用下方的 JSON 图标集地址。
  2. 添加到客户端在客户端找到图标集管理或添加图标集入口，粘贴链接并确认。不同客户端与版本的入口名称可能不同。
  3. 为策略组挑选图标加载完成后，在支持自定义图标的策略组中，选择 Qure 图标集并挑选图标。
ICON SET / JSON
https://raw.githubusercontent.com/aaANDkk/Qure_Style_SVG/main/Other/Qure-Style-SVG.json

Bettbox 已内置此图标包，可以先查看内置列表。仅支持 PNG 的客户端无法直接使用这套 SVG 图标集。

ONE SMALL DETAIL

喜欢哪一枚，就带走哪一枚。

不必导入整套图标。支持 SVG 图片链接的客户端，可以直接使用单个图标。

  1. 找到喜欢的图标在上方图标库搜索名称，点击图标打开预览。
  2. 粘贴图标链接点击“复制图标链接”，粘贴到客户端的自定义图标地址中。
  3. 也可以下载原图需要本地文件时，点击“下载 SVG”；需要嵌入网页时，可使用“复制 SVG 源码”。
EXAMPLE / ChatGPT.svg
https://raw.githubusercontent.com/aaANDkk/Qure_Style_SVG/main/icon/svg/common/ChatGPT.svg

文件名区分大小写。品牌与服务位于 common 目录，地区与旗帜位于 flag 目录；直接从预览复制链接更方便。

MAKE IT PART OF YOUR FLOW

为策略组，写上一枚图标。

在 Mihomo / Clash 配置的目标策略组中，添加 icon 字段。显示效果取决于客户端是否支持该字段与 SVG。

  1. 复制配置片段打开图标预览，点击“复制配置片段”。
  2. 放入目标策略组将 icon 字段放进目标策略组中，与 name、type 等字段保持相同缩进；已有 icon 时替换原值。
  3. 保存并查看效果保存并重新加载配置，在支持的客户端中查看效果。
POLICY GROUP / YAML
icon: "https://raw.githubusercontent.com/aaANDkk/Qure_Style_SVG/main/icon/svg/flag/Japan.svg"

搭配实验室用于预览图标效果，修改会自动保存在当前浏览器。要在客户端使用图标，请复制图标链接或配置片段。
