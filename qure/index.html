02 USAGE GUIDE

使用说明

QUICK START

支持整套图标包导入或单个图标引用。
根据所用应用或平台选择对应方式。

ICON SET / JSON

导入 JSON 图标包

适用于支持 JSON 图标集与 SVG 矢量格式的应用或工具。

  1. 复制清单链接使用下方的 JSON 图标包索引地址。
  2. 添加到应用在目标应用中找到图标集管理或导入入口，粘贴链接并确认。不同应用与版本的入口名称可能不同。
  3. 挑选并应用图标加载完成后，在需要自定义图标的位置选择 Qure 图标集并挑选对应图标。
ICON SET / JSON
https://raw.githubusercontent.com/aaANDkk/Qure_Style_SVG/main/Other/Qure-Style-SVG.json

清单中的所有图标均为 SVG 矢量格式；仅支持 PNG 的应用无法直接使用这套 SVG 图标集。

SINGLE ICON / URL

直接使用单个图标

不必导入整套图标。支持 SVG 图片链接的应用或网页，可以直接使用单个图标。

  1. 搜索目标图标在上方图标库搜索名称，点击图标打开预览。
  2. 粘贴图标链接点击“复制图标链接”，粘贴到需要自定义图标的地址栏中。
  3. 也可以下载原图需要本地文件时，点击“下载 SVG”；需要嵌入网页时，可使用“复制 SVG 源码”。
EXAMPLE / ChatGPT.svg
https://raw.githubusercontent.com/aaANDkk/Qure_Style_SVG/main/icon/svg/common/ChatGPT.svg

文件名区分大小写。品牌与服务位于 common 目录，地区与旗帜位于 flag 目录；直接从预览复制链接更方便。

YAML / CONFIG

在配置文件中指定图标

在支持 YAML 配置的应用或组件中，为目标条目添加 icon 字段。显示效果取决于对应工具是否支持该字段与 SVG。

  1. 复制配置片段打开图标预览，点击“复制配置片段”。
  2. 放入目标条目将 icon 字段放进目标条目中，与 name 等字段保持相同缩进；已有 icon 时替换原值。
  3. 保存并查看效果保存并重新加载配置，在支持的应用中查看效果。
ICON FIELD / YAML
icon: "https://raw.githubusercontent.com/aaANDkk/Qure_Style_SVG/main/icon/svg/flag/Japan.svg"

文件名区分大小写，点击“复制配置片段”或“复制链接”即可直接使用。
